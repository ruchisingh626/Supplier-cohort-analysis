# Supplier Cohort Analysis

## Project Overview
This project focuses on Supplier Cohort Analysis using Python to understand supplier activity and performance trends over time.

Suppliers are grouped into cohorts based on their first recorded activity month. Their subsequent activity and operational performance are analyzed to identify patterns and changes over time.

This project uses an Inventory & Supply Chain dataset to explore supplier activity, delivery performance, backorders, and operational efficiency.

## Project Objectives
- Identify supplier cohorts based on their first recorded activity.
- Analyze monthly supplier activity.
- Track supplier performance over time.
- Understand supplier lead-time trends.
- Analyze backorder patterns across supplier cohorts.
- Generate actionable supply chain insights.

## Dataset
**Dataset:** Inventory & Supply Chain Dataset

The dataset contains 1,200 records and 15 columns covering:
- Date
- Supplier
- Product Category
- Region
- Warehouse
- Inventory Level
- Units Sold
- Lead Time
- Order Accuracy
- Transportation Cost
- Backorder
- Order Status

## Project Workflow

### 1. Data Loading
Imported the inventory and supply chain dataset using Pandas.

### 2. Data Cleaning
- Checked missing values.
- Removed duplicate records.
- Standardized column names.
- Converted date columns into datetime format.
- Checked numerical and categorical variables.

### 3. Exploratory Data Analysis (EDA)
Analyzed inventory levels, units sold, suppliers, warehouses, and transportation costs.

### 4. Supplier Cohort Identification
Grouped suppliers based on their first recorded activity month.

### 5. Cohort Analysis
Analyzed supplier activity across subsequent months to understand operational patterns.

### 6. Supplier Performance Analysis
Evaluated suppliers based on:
- Average lead time
- Order accuracy
- Backorder rate
- Transportation cost

### 7. Data Visualization
Created charts and visualizations to understand supplier activity and performance trends.
